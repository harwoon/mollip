# 그룹 목표 진행률 안내 모달 디자인

## 목적

그룹 페이지의 `전체 달성률`이 어떤 값으로 계산되었는지 사용자가 현재 화면에서 바로 이해할 수 있게 한다. 그룹 전체 평균이 아니라, 그룹에서 설정한 목표를 기준으로 산출한 로그인 사용자의 개인 진행률이라는 점도 명확히 안내한다.

## 범위

- 그룹 목표 카드 우측 상단에 정보 버튼을 추가한다.
- 버튼을 누르면 현재 사용자의 실제 목표 값과 개별 진행률을 보여주는 소형 모달을 연다.
- 기존 그룹 목표 조회 응답을 사용하며 API와 백엔드는 변경하지 않는다.
- 그룹 목표 계산 공식 자체는 변경하지 않는다.

## 정보 버튼

- 카드 헤더 우측 상단에 원형 `i` 정보 버튼을 배치한다.
- 버튼은 실제 `button` 요소와 `aria-label="전체 달성률 계산 안내 열기"`를 사용한다.
- 기본 상태는 흰색 또는 옅은 표면색 배경과 중립 테두리를 사용한다.
- hover와 keyboard focus 시 그룹 색상을 활용해 배경색, 테두리, 아이콘 색상, 그림자를 변화시킨다.
- hover 시 버튼이 위로 약간 이동해 클릭 가능한 요소임을 전달한다.
- active 상태에서는 이동량을 줄여 눌리는 감각을 준다.

## 모달 동작

- 기존 공통 `AppModal`을 이용한 중앙 소형 모달로 구현한다.
- 정보 버튼 클릭으로 열고, 닫기 버튼과 배경 영역 클릭으로 닫는다.
- 모달 제목은 `전체 달성률 계산 안내`로 표시한다.
- 설명은 `각 목표의 진행률을 계산한 뒤 동일한 비중으로 평균을 구해요.`로 표시한다.
- 별도의 네트워크 요청을 발생시키지 않고 이미 조회한 `goals`와 `overallAchievementRate`를 전달한다.

## 모달 내용

모달 본문에는 다음 열을 가진 표를 표시한다.

| 열 | 내용 |
|---|---|
| 목표 | 주간 최소 공부시간, 주간 도전 공부시간, 개인 Todo 달성률, 주간 출석일 |
| 현재 / 목표 | 각 목표의 `currentValue`, `targetValue`, `unit`을 사용자 친화적으로 변환한 값 |
| 개별 진행률 | 서버가 반환한 `progressRate` |

시간 값은 카드와 동일하게 시간·분 형식으로 표시한다. 퍼센트와 출석일도 카드의 기존 표시 형식을 따른다. 진행률은 읽기 쉬운 수준으로 불필요한 후행 소수점을 제거한다.

표 아래에는 다음 계산 규칙을 안내한다.

- 개별 진행률은 `(현재값 / 목표값) × 100`으로 계산한다.
- 목표를 초과해도 전체 평균에는 최대 100%까지만 반영한다.
- 모든 등록 목표는 동일한 비중으로 평균한다.
- 표시되는 값은 그룹 전체 평균이 아니라 현재 사용자의 개인 진행률이다.

현재 데이터로 계산한 요약도 함께 표시한다.

`(개별 진행률의 합계) ÷ 목표 개수 = 전체 달성률`

서버에서 받은 소수점 값을 사용하고, 카드에 표시되는 최종 퍼센트는 기존과 동일하게 정수 반올림한다.

## 컴포넌트 경계와 데이터 흐름

- `GroupGoalSection`이 모달 열림 상태를 관리한다.
- `GroupGoalSection`은 기존 응답의 `goals`, `overallAchievementRate`, `groupColor`를 안내 모달에 전달한다.
- 안내 모달은 표시와 값 포맷만 담당하고 진행률을 새로 계산하지 않는다. 서버 계산 결과와 화면 설명이 어긋나지 않게 하기 위함이다.
- 반복되는 목표명과 단위 포맷이 필요하면 작은 표시 유틸리티로 분리하되, 이번 기능과 직접 관련 없는 리팩터링은 하지 않는다.

## 반응형과 접근성

- 데스크톱에서는 표 형식을 유지한다.
- 좁은 화면에서는 각 행을 목표별 세로 카드 형태로 배치해 가로 스크롤을 피한다.
- 정보 버튼은 마우스 hover뿐 아니라 `:focus-visible`에서도 동일하게 구분된다.
- 모달은 `role="dialog"`, 제목 연결, 닫기 버튼의 접근 가능한 이름을 기존 `AppModal`을 통해 제공한다.
- 색상만으로 상태를 전달하지 않고 텍스트 값을 함께 표시한다.

## 오류 및 빈 상태

- 목표가 없으면 정보 버튼을 숨긴다. 설명할 계산 대상이 없기 때문이다.
- 누락되거나 잘못된 숫자는 기존 화면 정책과 동일하게 0으로 안전하게 표시한다.
- 전체 달성률은 화면과 동일하게 0~100 범위로 제한한다.

## 테스트 및 검증

- 목표별 현재값, 목표값, 진행률이 모달에 표시되는지 검증한다.
- Todo 목표를 초과한 진행률이 100%로 표시되는지 검증한다.
- 정보 버튼 클릭으로 모달이 열리고 닫기 동작이 작동하는지 검증한다.
- 목표가 없을 때 정보 버튼이 노출되지 않는지 검증한다.
- 프런트 프로덕션 빌드와 관련 파일 린트를 실행한다.
- 데스크톱과 모바일 너비에서 표/카드 레이아웃을 확인한다.

## 제외 범위

- 백엔드 목표 계산식 변경
- 그룹 전체 구성원의 평균 달성률 추가
- 목표별 가중치 설정
- 새로운 API 또는 데이터베이스 필드 추가
